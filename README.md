# Mini Router

An API gateway that lets AI agents discover, inspect, and pay for tool calls through one API key.

> Work in progress, currently building v0.1 (Engine).

## Planned
- v0.1: Connector engine (tools defined as TOML files)
- v0.2: HTTP API + Postgres
- v0.3: Prepaid wallet + Stripe (test mode)
- v0.4: MCP server for AI agents + deployment
